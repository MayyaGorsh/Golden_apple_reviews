# Golden Apple Reviews Analysis

Проект анализа пользовательских отзывов о товарах «Золотого Яблока». Ноутбук объединяет разведочный анализ данных и NLP-пайплайн: очищает текстовые поля, определяет язык, классифицирует тональность и формирует признаки для выделения лояльных и нелояльных клиентов.

## Что реализовано

- загрузка и объединение данных из Google Sheets и Google Drive;
- анализ количества, рейтинга и стабильности отзывов по товарам и месяцам;
- эвристическое определение русских, английских, казахских и смешанных текстов;
- нормализация полей «Достоинства» и «Недостатки»;
- распознавание пустых по смыслу ответов вроде «нет», «не нашла» и «без минусов» с помощью регулярных выражений и fuzzy matching;
- анализ тональности полей отзыва с помощью мультиязычной модели `tabularisai/multilingual-sentiment-analysis`;
- очистка, удаление стоп-слов и лемматизация русскоязычного текста;
- построение прототипов явно лояльных и нелояльных отзывов;
- экспорт обработанного датасета в CSV.

## Структура анализа

1. Загрузка и первичная проверка данных.
2. EDA по товарам и временным периодам.
3. Определение языкового состава отзывов.
4. Очистка полей с достоинствами и недостатками.
5. Классификация тональности.
6. Лемматизация и подготовка текстовых признаков.
7. Выделение сегментов лояльных и нелояльных клиентов.

## Технологии

- Python, Pandas, NumPy;
- PyTorch и Hugging Face Transformers;
- RapidFuzz и регулярные выражения;
- pymorphy3 и NLTK;
- Google Colab, Google Sheets и Google Drive.

## Запуск

Проект подготовлен для запуска в Google Colab.

1. Откройте [`golden_apple_reviews_analysis.ipynb`](golden_apple_reviews_analysis.ipynb) в Colab.
2. Последовательно выполните все ячейки.
3. После завершения будет сформирован файл `df_out.csv` с очищенными текстами, метками тональности и лемматизированными признаками.

Для локального запуска установите зависимости:

```bash
pip install -r requirements.txt
```

Ячейку с `google.colab.files.download` при локальном запуске можно пропустить.

## Результат

На выходе получается подготовленный датасет для дальнейшей аналитики, сегментации клиентов и построения моделей на основе отзывов. Пайплайн позволяет отделить содержательные достоинства и недостатки от формальных ответов, сопоставить текстовую тональность с оценкой и рекомендацией пользователя и найти товары с наиболее стабильной обратной связью.

## Ограничения

- определение языка основано на составе символов и не заменяет полноценную языковую модель;
- sentiment-модель используется без дополнительного обучения на домене косметических отзывов;
- исходные данные загружаются из внешних источников и не хранятся в репозитории.
